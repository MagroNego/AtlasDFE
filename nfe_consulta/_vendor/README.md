# Leitor do Aging List

O arquivo `pypdf-6.21.4.zip` contém os fontes Python da distribuição
`pypdf 6.21.4` e a licença BSD de três cláusulas. O Atlas importa o leitor
diretamente do ZIP para converter o relatório original do Infor LN.

Para atualizar o leitor, preserve os arquivos `.py` e `py.typed` do pacote
`pypdf` e o arquivo `licenses/LICENSE` da distribuição. Atualize o nome
do arquivo em `aging_pdf.py` e valide a conversão de um relatório do LN.
